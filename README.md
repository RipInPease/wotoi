# wotoi - worst overall tracker of issues

## What is this shit?

This is an issue tracker inspired by Tsoding's [tatr](https://github.com/tsoding/tatr)

## Installation

```
$ git clone https://github.com/RipInPease/wotoi.git
$ cd wotoi
$ cargo build --release
$ sudo cp target/release/wotoi /usr/bin
```

## Usage

### To create a new issue:
```
$ wotoi -c "Name_Of_Issue"
$ wotoi --create "Name_Of_Issue"
```

### To delete an issue:
```
$ wotoi -r "Name_Of_Issue"
$ wotoi --remove "Name_Of_Issue"
```
